# Scriptures in View — Frontend

This is the web interface for Scriptures in View.

## What users can do here

- Open **Chapel Control** to search, stage, and send verses live
- Open **Sacred Display** for projection screens
- Read About, Contact, Privacy, Terms, and Downloads pages

## Run locally

```bash
npm install
npm run dev --workspace=frontend
```

The frontend connects to the backend server at `http://localhost:3000` in development.
