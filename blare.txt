ISSUE 9 — Context expansion modal + related scriptures
  Commit: f511218 — feat: add semantic related-scripture suggestions
                     and fix Electron animations
  Status: DONE

  a) CHAPTER TAB
     - "☰ Context" button added to live preview card
     - Opens modal with Chapter tab showing all verses in current chapter
     - Current live verse highlighted in gold
     - Each verse row: Stage / +List / ●Live action buttons
     - Fetches from existing /browse/verses?chapter_id= endpoint

  b) RELATED TAB (Semantic ML — no generative AI, no API cost)
     - Uses Xenova/all-MiniLM-L6-v2 transformer model (384-dim embeddings)
     - Model: ~90MB, downloaded once, cached locally, works offline after
     - verse_embeddings table in SQLite (63MB for 41k verses)
     - Embeddings computed lazily in background at server startup
       (batches of 50, setImmediate yields event loop between batches)
     - Resume-safe: LEFT JOIN diff finds only missing verse embeddings
     - +0.15 cosine similarity boost when verses share a DOCTRINE_ALIASES
       theological concept (atonement, baptism, grace, faith, etc.)
     - Concept tag shown on each result card (e.g. "ATONEMENT")
     - Fallback to FTS/BM25 while embeddings are still computing
     - REBUILD_EMBEDDINGS=true env var forces full recompute

  WHY THIS IS TRUE ML:
     TF-IDF and BM25 are statistical formulas (not ML).
     all-MiniLM-L6-v2 is a neural network trained on 1 billion sentence
     pairs that learned semantic meaning. It understands that "redemption"
     and "deliverance" are the same concept — even when words don't overlap.
     No API cost. No internet after first model download. Works in Electron.
